## 🧠 Key Learnings

- **Instance attributes** belong to individual objects.
- **Class attributes** are shared by all objects of a class.
- **Instance methods** work with object-specific data and use `self`.
- **Class methods** work with class-level data and use `cls`.
- **Static methods** do not depend on object or class state.
- `@classmethod` and `@staticmethod` are decorators used to define special method types.
