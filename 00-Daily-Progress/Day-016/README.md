## 🎯 Goal

Learn the concept of **Abstraction** in Python OOP and understand how to hide unnecessary implementation details while exposing only the essential functionality.

---

## 📚 Topics Covered

- Abstraction
- Abstract Classes
- Abstract Methods
- `ABC` (Abstract Base Class)
- `abstractmethod`
- Implementing abstract methods in child classes
- Hiding implementation details
- Difference between abstraction and implementation

---

## 🧠 Key Learnings

- Abstraction focuses on **what an object does** rather than **how it does it**.
- An abstract class provides a common structure for its child classes.
- Abstract methods must be implemented by concrete child classes.
- Python provides `ABC` and `@abstractmethod` for implementing abstraction.
- Abstraction helps create clean, organized, and maintainable code.
