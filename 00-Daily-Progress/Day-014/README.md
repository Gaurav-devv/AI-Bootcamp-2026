## 🎯 Goal

Complete the core concept of **Inheritance** in Python OOP and understand how one class can reuse the properties and methods of another class.

---

## 📚 Topics Covered

- Inheritance
- Parent class
- Child class
- Single Inheritance
- Multiple Inheritance
- Multilevel Inheritance
- Hierarchical Inheritance
- Hybrid Inheritance
- Method Resolution Order (MRO)
- `super()`
- Constructor inheritance
- Method overriding

---

## 🧠 Key Learnings

- A child class can inherit attributes and methods from a parent class.
- Inheritance promotes code reuse.
- `super()` is used to access methods or constructors from the parent class.
- Multiple inheritance allows a class to inherit from more than one parent.
- MRO determines the order in which Python searches for methods.
- A child class can override a method inherited from its parent.
