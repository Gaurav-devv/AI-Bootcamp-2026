- `KeyError`
- `Exception`
- Basic exception handling practices

---

## 🧠 Key Learnings

- Errors can cause a program to stop unexpectedly.
- Exceptions can be handled using `try-except`.
- Specific exceptions should be handled whenever possible.
- `else` runs when no exception occurs.
- `finally` runs whether an exception occurs or not.
- Exception handling makes programs more reliable and user-friendly.
