## 🧠 Key Learnings

- `__init__()` is a special method used to initialize an object.
- It is automatically called when an object is created.
- `self` refers to the current object.
- Constructors can accept parameters to initialize different objects with different values.
- Constructors help reduce repetitive code when creating objects.
