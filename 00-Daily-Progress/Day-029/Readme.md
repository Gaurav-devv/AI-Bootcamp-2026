## Overview

On Day 29, I completed the first module of Statistics — Visualization, covering how to organize, summarize, and represent data using different tables and graphs.

The module covered topics from **1.1 to 1.10 (Pages 1–65)**, starting with basic data tables and progressing to frequency distributions and histograms.

## Topics Covered

### 1. Statistics — Introduction
- Introduction to the Visualization module.
- Understanding the importance of visual representation in statistics.

### 2. One-Way Table
- Meaning of data and data tables.
- Organizing data into rows and columns.
- Understanding individuals and variables.
- Qualitative vs. quantitative variables.
- Counter-question test.
- Understanding table orientation.

### 3. Bar Graph
- Creating frequency tables from raw categorical data.
- Representing category counts using vertical bars.
- Comparing visual analysis with tabular analysis.

### 4. Pie Chart
- Using frequency counts to calculate percentage occurrences.
- Representing data as proportions of a whole.
- Understanding the 100% circle.
- Interpreting slices according to their percentages.

### 5. Line Graph
- Deriving line graphs from bar graph values.
- Understanding continuous time-series trends.
- Tracking changes over time, such as monthly expenses.
- Knowing when to use a line graph instead of a bar graph.

### 6. Ogives
- Understanding cumulative frequency.
- Constructing cumulative frequency tables.
- Representing cumulative data graphically.

### 7. Two-Way Table
- Understanding independent and dependent variables.
- Analyzing multi-year data (2020–2023) by month.
- Applying the two-counter-question test.
- Introduction to grouped bar graphs.
- Introduction to dot plots.

### 8. Relative Frequency Table
- Converting two-way table counts into percentages.
- Understanding column-related relative frequencies.
- Understanding row-related relative frequencies.
- Comparing percentages across categories.

### 9. Joint Distribution
- Comparing two-variable distributions.
- Using row and column percentages.
- Understanding relationships between two variables.
- Example: Weight Lost vs. Total Hours of Workout.

### 10. Histogram / Histograms
- Understanding continuous numerical data.
- Grouping continuous data into bins or intervals.
- Calculating bin frequencies.
- Calculating the data range.
- Determining appropriate bin widths.
