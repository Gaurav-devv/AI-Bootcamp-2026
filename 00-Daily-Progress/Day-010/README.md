## 🎯 Goal

Build a practical Python project using the file-handling concepts learned in Day 009.

The goal was to understand how file handling can be used in a real-world application to store, read, update, and manage data.

---

## 🛠️ Project

### File-Based Data Management Project

Built a small project that uses files to store and manage information.

The project demonstrates how Python can:

- Create files
- Read data from files
- Write new data
- Append new information
- Update stored information
- Search/read existing data
- Handle file operations safely

---

## 📚 Concepts Used

- `open()`
- File modes:
  - `r` — Read
  - `w` — Write
  - `a` — Append
- `read()`
- `readline()`
- `readlines()`
- `write()`
- `with open()`
- User input
- Conditional statements
- Loops
- Functions
- Basic error handling
- File-based data storage

---

## 🧠 Key Learnings

- File handling allows programs to store data permanently.
- `with open()` is useful because it automatically closes the file.
- Different file modes are used for different operations.
- File handling can be combined with functions, loops, conditions, and user input to create practical applications.
- A simple file can be used as basic persistent storage before learning databases.
